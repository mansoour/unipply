# Unipply Brand & Store Assets

Runtime extension icons live in [`/assets`](../assets) (referenced from `manifest.json`) — nothing
in this folder is loaded by the extension itself.

## branding/
Transparent-background icon, logo, and wordmark exports (source + 2x) for marketing use — website,
docs, social, etc.

## store/
Chrome Web Store listing graphics: `store-icon-128.png`, `small-promo-440x280.png`,
`marquee-1400x560.png`. Add 1–5 real interface screenshots to `store/screenshots/` at 1280x800
(preferred) or 640x400 before submitting the listing — none exist yet.

## ui/
Welcome/onboarding hero images (`welcome-hero-1000x400.png`, `welcome-hero-1200x480.png`) for a
future in-extension welcome page — not wired up yet.
